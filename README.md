# Netflix Insights Dashboard

A Streamlit dashboard for exploring Netflix viewing and subscription data.

## Run locally

Install dependencies from `requirements.txt`, then start the app with:

```text
streamlit run app.py
```

The app uses illustrative demo data when no `netflix.csv` file is present. You can also upload a CSV from the dashboard sidebar.

## Deploy on Streamlit Community Cloud

1. Select this GitHub repository and the `main` branch.
2. Set **Main file path** to `app.py`.
3. Deploy. Streamlit installs dependencies from `requirements.txt`.

`Untitled (2).py` remains as a compatibility entry point for deployments that already use that filename.
